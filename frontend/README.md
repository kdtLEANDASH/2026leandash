# Leandash Frontend

이 프로젝트는 React + Vite 기반의 프런트엔드입니다.

-업데이트
다크모드
단체 채팅방 유저목록 표시
비밀번호 변경 버튼 누르면 모달창 표시
커뮤니티 댓글 페이지네이션
커뮤니티 부서 게시판
채팅 이모니콘, 파일 추가
최고 관리자에 한해 직원들 비밀번호 변경 가능

## 기술 스택
- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React

## 실행 방법
```bash
npm install
npm run dev
```

## 빌드
```bash
npm run build
```
